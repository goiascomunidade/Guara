Resumo executivo

  • Conversa por voz continua, sem botao obrigatorio.
  • Core orientado a contratos para plugar STT, TTS, LLM e tools.
  • MCP/n8n como trilha no-code prioritaria para ecossistema de ferramentas.
  • Barge-in, streaming incremental e telemetria local no baseline.
  • Roadmap fechado para hardening realtime, memoria, marketplace e proatividade controlada.

Roadmap tecnico por fase

Fase A - Hardening realtime

Auth por token, backpressure por canal, timeout de stream e heartbeat WS.

Fase B - Memoria RAG real

Provider vetorial, injecao de contexto por relevancia e sumarizacao persistida.

Fase C - Marketplace operacional

Indice de ferramentas, CI de validacao e fluxo de aprovacao humana.

Fase D - Proatividade controlada

Scheduler por ferramenta com enforce de confirmacao para acao critica.

Fase E - Providers reais

Integracoes cloud/local com medicao de P95 e politica de fallback.

L1 · Visão Geral

O que é
o Guará?

Guará é uma fundação open source para arquitetura de agentes voice-to-voice. Construído Python-first com foco em extensibilidade por interfaces de domínio — permite trocar STT, TTS, LLM e ferramentas por configuração, sem reescrever o core.

Projetado para rodar local em Docker all-in-one, com integração no-code via MCP e n8n, e evolução para autonomia por ferramenta em modos controlados de proatividade: Manual · Agenda · Autônomo.

Arquitetura

Os 5 Níveis do Guará

Uma plataforma construída em camadas independentes — troque qualquer peça sem tocar nas demais.

5
Transporte
Interface com o mundo exterior. Voz, texto e eventos chegam e saem via HTTP, WebSocket e SSE.
4
Orquestrador
O maestro da conversa. Gerencia turnos, coordena ferramentas e controla os estados da sessão.
3
Core Engine
O coração. Barramento de eventos tipados, memória de curto prazo e execução paralela de ferramentas.
2
Provedores
As peças intercambiáveis. STT, LLM e TTS trocam sem alterar uma linha do núcleo.
1
Plugins & Adaptadores
A extensão sem código. Conecte ferramentas externas via MCP, n8n ou SDK Python diretamente ao núcleo.
Nível 5: protocolo  ·  Nível 1: extensão  ·  cada camada independente
L3 · Componentes

Módulos do Core

Event Bus
core/events.py · core/telemetry.py
Eventos tipados e versionados com event_name, trace_id e session_id. Backbone de telemetria local com opt-in para exportação.
Session Controller
core/session.py
Ciclo de vida completo da sessão: start_session, push_audio_frame, interrupt, end_session. Controla estados e rastreia contexto conversacional.
Orchestrator
core/orchestrator.py
Ponto de entrada LLM + ferramentas. Gerencia turn-taking, tool routing e decisão de sempre run_llm após execução de tool no MVP.
Tool Runtime
core/tool_runtime.py
Execução paralela limitada por sessão, scheduling por dependência declarada, timeout por tool e cancelamento interruption-aware por política.
Memory Store
core/memory.py · core/summarizer.py
Memória de curto prazo local com TTL configurável. Sumarização automática por threshold híbrido (tokens + mensagens). Abstração para RAG no MVP.
Plugin Manifest
core/manifest.py · plugins/sdk.py
Manifesto versionado com tool_id, risk_level, autonomy_modes. SDK para registrar funções Python com schema inferido de assinatura e docstring.
Provider Registry
core/provider_registry.py
Registro e troca de providers STT/TTS/LLM por configuração. Switch manual via /providers/switch sem reinicialização do runtime.
Streaming
core/streaming.py
Gerenciamento de chunks para TTS otimista. Fragmentação por pontuação com suporte a max_chunk_chars e buffering adaptativo para naturalidade da fala.
MCP Adapter
adapters/mcp_http.py · mcp_tool_provider.py
Descoberta e execução de ferramentas remotas via MCP HTTP. Tools externas disponíveis imediatamente após /tools/register-mcp.
